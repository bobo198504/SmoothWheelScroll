## 1. 模型：速度预算 → 每格行程（3.0，取代 1.6.1 的物理动力模型）

### 为什么换

1.6.1 的模型按「冲量 + 幂律摩擦」工作：一格给一个**速度**，速度再自己衰减。
它对手感很好，**但只适合有格鼠标**：无级（自由滚动）鼠标一格只有 15~20 delta 却发得很密，
按「一格一个冲量」算，它会**连击涨 8 倍快**、而有格鼠标永远涨不满
（实测两者总行程差 **9.33 倍**）。用户的要求是**一个模型同时兼顾两种设备**。

### 定稿规则（用户逐条设计）

单位换成 **delta**（设备无关的物理量：一格 = 那条消息自己的 delta，普通 120、无级 15~20）：

```
travel = start + (cap − start) × min(budget / budgetDeltas, 1)

  cap    = 这条消息自己的 delta（普通可到 120、无级封顶 15~20）
  start  = 慢轮时一格走多少 delta（绝对量，不按比例）
  budget = 一个会衰减的运行量：每条消息 + 自己的 delta，并按经过时间回落
```

- **预算按时间衰减**（时间常数 300ms），所以它跟随当前速度：慢慢转就加得慢，
  一直匀速转就停在一个稳态 —— 手感是「越转越有劲，停下来就落回去」。
- **衰减用欧拉步进**，不是 `exp`：不粘的有格鼠标消息间隔（125ms）相对 300ms 不算小，
  `exp` 会让两种设备的稳态**不同**（实测差 14%）；欧拉步进的稳态恰为 `rate × tau`，
  两种设备一致（实测差 **4.8%**）。
- **设备无关性**（`_diag/combo_sequence_probe.cpp`，用户指定场景：一次滑动 960 delta）

  | 加速由什么驱动 | 普通合计 | 无级合计 | 差 |
  |---|---|---|---|
  | 消息**条数**（最初想法） | 96 | 896 | **9.33 倍** |
  | 累计 **delta**（定稿） | 730 | 742 | **1.02 倍** |

### 投递层未改

`routing.h` / `FilterFor` / `Delivery` 一行未动：`one page` 仍排除、MIDI 与主视图竖直轴
仍按「接收方表达得出的最细步进」投递、触控板反向保留。**本版只换模型，不碰投递。**

## 2. 竖直缩放仍用 1.6.1 的曲线模型

主视图竖直缩放（`View: Zoom vertically`）单独走 **1.6.1 的曲线模型**
（`src/anim161_core.h`，与 1.6.1 **逐字节相同**），因为它那条轴是**固定 2px 刻度、每次调用独立取整**，
细流会造成反复微跳；用户实测 1.6.1 的手感最舒服。参数是用户自己的 1.6.1 设置
（`start=15%`、`accel=13.61%`），**不在面板上**。

## 3. 设置面板：4 个滑杆 + 运动轨迹图

`src/smooth_wheel_scroll.cpp` 里的面板重做：

| 滑杆 | 它改什么 | 范围（默认） |
|---|---|---|
| **Glide length** | 一格动画的时长（水平时间轴） | 100–300 ms（**200**） |
| **Slow step** | 慢轮一格走多少 delta | 1–10 d（**5**） |
| **Ramp-up** | 转多少 delta 才涨满到整格 | 60–2000 d（**1000**） |
| **Top speed** | 最快时能冲到自身速度的几倍 | 1.0–2.0 ×（**1.5**） |

- **运动轨迹图**：脚本化滚动跑一遍，画「滚轮自己的整步路径」（灰虚线）与「本插件给的平滑路径」
  （按滑杆分段上色），并让**一颗球**沿路径跑。**每个滚轮消息发一颗球**（最多 6 颗同时在飞）。
  **Enable 关掉时球也跑**，走的是整步（方块）那条。
- 四个参数**各占一个视觉通道**：Glide = 时间轴 / Slow step = 膝点高度 / Ramp-up = 坡度 /
  Top speed = 纵轴缩放（原生参考线在 `1/Top` 处，`Top=1.0` 时顶线正好压在它上面）。
- **刻度按数值取**（1/2/5 × 10ⁿ），所以拉 Glide / Top 时刻度跟着缩放。
- 总开关关掉 = **完全放行**，滚轮回到 REAPER 原生行为（钩子仍安装，可运行时切回）。

## 4. 默认值迁移

四个默认值改为 **200 / 5 / 1000 / 1.5**。extstate 里若还**恰好等于旧默认**
（150 / 1 / 600 / 1.0），载入时**一次性**升级；**用户真调过的值一律保留**（`defrev` 键）。
