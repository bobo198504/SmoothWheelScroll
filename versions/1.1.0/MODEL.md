# SmoothWheelScroll 模型 1.1.0

**状态：用户已验收（"丝滑了"）。基于 1.0.0 优化而来。**

## 相对 1.0.0 的三处改动

1. **渐入改为"每格独立斜坡"**（修 1.0.0 的结构缺陷）
   1.0.0 用**一条共享斜坡**乘累加总量；到第 2 格时 `S(x)` 已达 ~0.84，导致该格速度**84% 瞬间灌入**
   （实测速度 9 → 109，读者感受为"一跳一跳"）。改为每格各自从到达时刻渐入后，突跳从 +1419% 降到 +310%
   （= 单格本身水平）。
   **单格手感完全不变**（单格本来就只有一条斜坡），所以收尾形状未动。

2. **滚动中窗口 30ms**（`kMovingOnsetMs`）
   每格独立后连滚能量会降；后续格用 30ms 短窗口（首格仍用长窗口保持柔），把连滚总量补回 1.0.0 的 ~1.5% 内。

3. **RELEASE 与渐入窗口合并为一个 150ms 参数**
   `kOnsetRatio = 1.0` ⇒ 渐入窗口 == RELEASE。一个参数同时决定"起步时长"和"释放时长"，同步变化。

## 冻结参数

| 名称 | 值 |
|---|---|
| Start | 15 % |
| Accel | 3.6 % |
| **RELEASE** | **150 ms**（同时 = 渐入窗口） |
| frictionPow | 0.8 |
| onsetRatio | 1.0 |
| movingOnsetMs | 30 |
| tempoRefMs | 120 |
| relaxMax | 4 |
| burstGapMs | 250 |
| 输出 | `kFineValues=true`（1/256 单位）、普通计时器 |

## 基准数值（tick=15.6ms，单位=wheel units）

| 操作 | 总行程 |
|---|---|
| 单格 | 1.798（峰值@98ms，用时240ms） |
| 10 格 @250ms | 41.44 |
| 10 格 @120ms | 54.35 |
| 10 格 @60ms | 131.02 |
| 10 格 @33ms | 241.62 |

**1.0.0 的单格数值 1.889 已被 1.1.0 有意改掉**（因为 RELEASE 从 100→150、渐入窗口 80→150）。
单格的"形状"（共享/独立斜坡）与 1.0.0 一致，仅时长参数不同。
