## 1. 水平滚轮（倾斜轮 / 拇指轮）

**报告**（论坛 **poydepzaj1616**）：MX Master 3S 拇指轮绑到 **977 / 979**（水平滚动/缩放的反向版）
**没有缓动**；而同一条 977 用 **Shift+竖轮**却丝滑。

### 诊断（两条，都实测证实）

| cmd | 走**表**时的 rel | 走**名规则**时的 rel |
|---|---|---|
| 988 / 977 / 990 / 979 | **0**（旧版）| **1** |

1. **同一条动作，两条规则答案不同。** `LookupAction` 命中即返回，**没设 `relativeAction`**（默认 `false`），
   而 `ClassifyName` 会按名字里的 `mousewheel` 设成 `true`。**表先试，所以表说了算**
   → 这些动作**要求滚轮闩锁**。
2. **`WM_MOUSEHWHEEL` 在整个 `src/` 里出现 0 次** —— 钩子只看 `WM_MOUSEWHEEL`，
   水平轮消息**不进钩子** → 闩锁**永远上不了**。

两条叠加 → 水平滚轮**必被拒**，走原生跳步。Shift+竖轮能过，因为竖轮经过钩子、上了闩。

### 做法（两处，性质不同）

1. **表项静态声明 `relativeAction = true`**（`routing.h`，16 行；**1.7.4 已含**）。
   1.7.4/1.7.5 的相对动作判定都走 `ClassifyName` 的 `mousewheel` 名规则
   （表里那 16 行只在**没有** `reaper-kb.ini` 可用时兜底），
   所以 `relativeAction` 是**表数据自带的冗余声明**。
   **它不是水平轮专属** —— **Shift+竖轮**驱动 977/988 也靠同一个名规则。
2. **`WM_MOUSEHWHEEL` 上闩**（`GetMsgProc`）：**只做设备判定 + 上闩**，
   **不做任何表面接管**（arrange/MCP/面板/列表都不镜像 —— 那些是竖轮手势，没有实测的水平对应物）。

### ★ 关键设计：两个轮子的状态**必须分开**

`DeviceTracker` 按"最近窗口里有几种不同幅度"判定。**共用一个跟踪器会互相污染**：
竖轮发整格 `120` 清零窗口，横轮的 `15,15` 混进同一窗口 → 幅度种数 ≥ 2 → **判成触控板 → 两轮都不缓动**。

所以按轴分成两套（`g_device`/`g_deviceH`、`g_lastDevTick`/`g_lastDevTickH`、
`g_lastDevKind`/`g_lastDevKindH`、`g_wheelTick`/`g_wheelTickH`），
**过滤规则、模型、投递全部共用**（`Kick` 本来就按 `spec.axis` 选 integrator）。

### 曾从 1.7.4 撤出、1.7.5 恢复（这段历史要留着）

**1.7.4 发布时把这一条整个撤掉了**，理由写进了当时的提交与文档：
**没有设备可实测** —— 需要确认"倾斜轮 / 拇指轮真实上报的 delta 形态"与"分类器怎么读它"，
两条都只能靠真设备。**发布物不宣布没测过的东西。**

**2026-10-10**：论坛测试者（有倾斜轮/拇指轮设备）反馈**使用正常** → 本条并入 **1.7.5**。

**恢复的做法**：从提交 `cc33664` 取回钩子分支（`git show cc33664:src/smooth_wheel_scroll.cpp`），
精确插回 `GetMsgProc`。**撤出时状态变量与跟踪器都特意留着**，所以只需加回这一段。

**`_diag/hwheel_probe.cpp` 的断言随发布状态切换**，这次已改回"处理器**存在**"。
（历史：1.7.4 期间它断言的是**相反**的事实 —— 那时候"检查通过"意味着功能**不在**。）

### ⚠️ 这个检查曾被两样东西骗过（教训）

它检查的是**源码文本**里有没有处理这个消息。前两版分别被：
1. **一句解释性注释**（撤出功能后注释还写着 `WM_MOUSEHWHEEL`）；
2. **DEV 日志里的一句帮助文字**（"V for the vertical one, H for the horizontal one"）

满足，**两次都报"通过"**，而功能并不存在。

**现在的做法**：只认**消息比较** `== WM_MOUSEHWHEEL` —— 只有真正的处理代码才有这个形式。
**一句注释或一句帮助文字能满足的检查，不是检查。**
