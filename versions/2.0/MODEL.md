## 模型三要素（缺一不可，这就是"手感"）

1. **冲量**：一格给一个速度。
2. **单一共享平滑渐入**：速度从静止"绕起"来（smoothstep）。
3. **幂律摩擦 + 刹车随节奏放松**（`p = 0.8`，`relax`）：末段"逐渐用力刹车"的收尾。

> 新增的 `kOnsetFadeNotches`（头 3 格过渡）、`softStart`（高速收力）、`relGain`（高速滑行）都在这套之上，
> 默认值保证单格与慢滚**逐位不变**。详见 `AGENTS.md` §7 / §11 / §18。

## 相对 1.6.1 发布版，本快照多出的东西

`versions/1.6.1/` 是**已发布**的；本快照是它之后的**本地未发布**工作状态，多出两处：

1. **`Kick` 改为按每条消息自己的份额推进**（参数名 `unitTravel` → `notches`）：
   `rollN_ += frac`、`target_ += claim * frac`。用途是让**无级鼠标**（把一格拆成多条小值上报）
   与普通鼠标走同一套累积。**普通鼠标（份额 = 1）逐位不变。**
2. **面板底部的原始滚轮监视器**：只读显示插件收到的**原始** delta / 间隔 / 修饰键 / 设备判定，
   用于开发不同品牌的鼠标。**不参与模型、不参与投递。**

（这两处都属于"往 3.0 的探索"，3.0 落地后大概率被取代；备份在此是为了**能回退**。）
